# Deforestation Data Processor

![GitHub release (latest by date)](https://img.shields.io/github/v/release/CIAT-DAPA/ganabosques_farm_data_processor) ![](https://img.shields.io/github/v/tag/CIAT-DAPA/gganabosques_farm_data_processor)

The Farm Data Processor container operates as an ETL (Extract, Transform, and Load) process focused on querying and processing information on livestock farms and conservation areas. It operates in three phases: the first involves constructing polygons using buffers, based on information from SAGARI; the second focuses on quality control of the polygons generated by GeoFarmer; and the third is responsible for delimiting polygons corresponding to conservation areas, considering official sources such as National Natural Parks, Regional Natural Parks, Páramo Zones, and Agricultural Frontiers.


### 🚀 How to Run the Pipeline

The pipeline can be executed from the command line with optional arguments to control which processing steps to run.

#### 📌 Full execution (all steps):
```bash
python main.py
```

#### 🛠️ Select specific steps:

```bash
python main.py -p 1 3
```
Runs only steps 1 and 3.

#### 🔁 Run from a specific step onward:

```bash
python main.py -f 2
```
Runs steps 2, 3, and 4.

#### 🧭 Available steps:

| Step | Description                              |
|------|------------------------------------------|
| 1    | Obtener datos de SAGARI                  |
| 2    | Validación de calidad de coordenadas     |
| 3    | Cálculo de buffers geoespaciales         |
| 4    | Guardar información de predios en MongoDB|

#### 📖 Help
To see help information at any time:
